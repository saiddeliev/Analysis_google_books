# Google Books Analysis

Проект посвящён анализу датасета Google Books с использованием Python.

## Используемые инструменты

- Python
- pandas
- numpy
- matplotlib
- seaborn
- Yandex DataLens

## Выполненный анализ

- первичный обзор данных;
- обработка пропущенных значений;
- поиск дубликатов;
- анализ выбросов;
- описательная статистика;
- корреляционный анализ;
- группировки и агрегации;
- сводная таблица `pivot_table`;
- визуализации: гистограмма, линейный график, столбчатая диаграмма, boxplot и heatmap.

## DataLens

В DataLens созданы:

- диаграмма количества книг по категориям;
- линейный график количества книг по годам;
- таблица количества книг и среднего рейтинга по языкам;
- дашборд с селектором языка.

## Файлы проекта

- `data/google_books_dataset.csv` — исходный датасет;
- `notebook/analysis.ipynb` — ноутбук с анализом.
